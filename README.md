
# 🥗 AI Diet Generation System

An intelligent web-based application that generates **personalized diet plans** based on user health data, lifestyle, and fitness goals.

---

## 🚀 Features
- ✅ Personalized diet plan generation  
- 🧠 AI/ML-based health prediction  
- 📊 User input analysis  
- 📄 Downloadable reports  
- 🎨 Modern UI  
- ⚡ Fast and responsive  

---

## 🛠️ Tech Stack

**Frontend:**  
HTML, CSS, JavaScript  

**Backend:**  
Python (Flask / FastAPI)  

**Machine Learning:**  
Scikit-learn, Pandas, NumPy  

---

## 📂 Project Structure
diet-generator/
│── frontend/
│── backend/
│── model/
│── static/
│── templates/
│── README.md

---

## ⚙️ How It Works
1. User enters health details  
2. Backend processes data  
3. ML model analyzes inputs  
4. Diet plan is generated  
5. Results displayed on UI  

---

## 🧪 Setup
git clone https://github.com/Arayana-sood/NutriAI-personalized-diet-generation

cd NutriAI-personalized-diet-generation
pip install -r requirements.txt
python app.py
